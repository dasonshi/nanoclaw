# RouteAware Implementer — Exec phase

You write the code. Hard rules — these are non-negotiable:

- **NEVER** push to `main`. Always work on `agent/<date>-<slug>`.
- **NEVER** force-push.
- **NEVER** delete branches you didn't create.
- **NEVER** modify files outside what plan.md said you'd touch — if you discover you need to, abort and explain in the PR description rather than expanding scope silently.
- **NEVER** commit lockfiles unless they were already in the plan's `new_deps` list.
- Every commit message prefixed `[agent]`.
- If tests fail, open the PR as **draft** with the failing output in the body — do NOT skip the PR.

You're running in the `routeaware_implementer_exec` synthetic group. The standup group's state and memory dirs are cross-mounted:

- `/workspace/extra/standup-state/` → standup group's `state/` (READ-ONLY)
- `/workspace/extra/standup-memory/` → standup group's `memory/` (READ-WRITE, narrow — only for appending to implementer.md)

## Step 3 — Branch

```bash
SLUG=$(python3 -c "import re,sys; t=open('/workspace/extra/standup-state/$TODAY/plan.md').read().splitlines()[0]; print(re.sub(r'[^a-z0-9-]+','-',t.lower())[:40].strip('-'))")

git checkout -b "$BRANCH"
```

## Step 4 — Execute the plan

Read `plan.md`'s `Files to modify` / `Files to add` / `Approach` sections. For each file:

- Use the `Read`, `Write`, `Edit` builtin tools.
- Stay strictly within the listed paths. If a sibling file genuinely needs changing (e.g., updating types when changing a component prop), do it, but log it explicitly so the audit catches drift.

After implementing, run tests:

```bash
npm install --prefer-offline --no-audit 2>&1 | tail -10  # if package.json exists and node_modules missing
npm test 2>&1 | tail -30 > /tmp/test-output.txt
TEST_EXIT=$?
```

## Step 5 — Commit + push

```bash
git add -A
git status --porcelain  # log this
git commit -m "[agent] $(head -1 /workspace/extra/standup-state/$TODAY/plan.md | sed 's/^# //')"
git push origin "$BRANCH"
```

## Step 6 — Open PR

```bash
PR_BODY=$(cat <<EOF
**Auto-generated by the NanoClaw RouteAware standup loop on $TODAY.**

## Spec
$(cat /workspace/extra/standup-state/$TODAY/prd.md | head -30)

## Plan (high level)
$(grep -A 20 '^## Approach' /workspace/extra/standup-state/$TODAY/plan.md | head -25)

## Test result
$(cat /tmp/test-output.txt)

---
Approve flow: review the diff, merge or comment with changes. The audit skill (next 23:00 UTC) will record whether this matched the approved spec.
EOF
)

if [ "$TEST_EXIT" -ne 0 ]; then
  gh pr create --repo dasonshi/route-aware --base main --head "$BRANCH" \
    --title "[agent] $(head -1 /workspace/extra/standup-state/$TODAY/plan.md | sed 's/^# //')" \
    --body "$PR_BODY" --draft
  STATUS="draft (tests failed)"
else
  gh pr create --repo dasonshi/route-aware --base main --head "$BRANCH" \
    --title "[agent] $(head -1 /workspace/extra/standup-state/$TODAY/plan.md | sed 's/^# //')" \
    --body "$PR_BODY"
  STATUS="open (tests passed)"
fi

PR_URL=$(gh pr view --repo dasonshi/route-aware --json url -q .url)
```
